# Modello dati

- `users`: account applicativi.
- `search_campaigns`: richieste di ricerca lanciate dagli utenti.
- `discovered_sites`: URL e domini trovati da provider ricerca.
- `service_profiles`: risultato strutturato dell'analisi.
- `evidence_items`: snippet e URL usati come prove.
- `analysis_runs`: traccia modello, versione prompt, stato ed errori.

Il sistema salva estratti testuali e metadati, non HTML completo.
